# thermometer changelog

Earlier history lives in the repository changelog.

## 0.2.0 - 2026-10-20

- Added Climb mode (frozen, proven harness; one hypothesis per iteration; keep only wins beyond noise with the regression gate green; full revert otherwise) in `references/climb.md`. Adapted from pstack by Lauren Tan (MIT).
- Added a "distrust the number" checklist in `references/distrust-the-number.md`, a diagnose-only mode in `references/diagnosis.md`, and cheapest-lever-first ordering for fixes.

## 0.1.0 - 2026-07-10

- Added repeatable performance baselines with multiple samples and spread reporting.
- Added profile-first bottleneck selection and one-hypothesis changes.
- Added like-for-like comparisons, correctness checks, and explicit inconclusive-result handling.
