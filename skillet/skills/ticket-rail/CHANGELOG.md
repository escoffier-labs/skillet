# ticket-rail changelog

## 0.1.0 - 2026-10-20

- Added the skill: issue intake and repro gate with frozen source coordinates, whole-thread reading, a bounded cause trace, classification, four dedupe outcomes, create-only-for-a-clear-live-net-new-bug, hold or verify mode when a fix already exists, and "no confirmed repro, no authored fix". Defaults to an internal verdict; public comments only on request. Adapted from the triage and reproduce playbooks in pstack by Lauren Tan (MIT), without its chat-automation specifics.
