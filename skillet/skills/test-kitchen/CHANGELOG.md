# test-kitchen changelog

## 0.1.0 - 2026-10-20

- Added the skill with two modes: create a project-local verify skill that drives the real app (launch, read-only doctor, drive recipes with stable handles, evidence rules, cleanup that kills only what the run started, a seeded feature map, proven once before handover), and maintain it (index hygiene, read-only source reader per feature, one live pass, triage into doc drift, harness gap, or product gap, ending clean, changed, or blocked). Never edits product code. Adapted from the create-verification-skill and maintain-verification-skill skills in pstack by Lauren Tan (MIT).
