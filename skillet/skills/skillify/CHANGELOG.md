# skillify changelog

Earlier history lives in the repo-level CHANGELOG.md.

## 0.2.0 - 2026-10-20

- Baseline first: run the realistic task on a fresh agent without the skill, record excuses verbatim, and build the rationalization and red-flag table from them.
- Match the form to the failure (prohibition plus table, positive recipe, required slot, observable predicate); micro-test wording against a no-guidance control with five or more reps.
- Validation step (links resolve, files exist, repo lint passes) and small portability rules (scripts via interpreter, no @-links, triggers-only descriptions).
- New mode: revise an existing skill from session evidence behind user-approved accept filters, with a tune-the-description route; points to the eighty-six skill when a mechanism can enforce the lesson.
- New references: `references/blind-eval.md` (blind A/B eval procedure) and `references/skill-testing.md` (testing method). Added the shared Untrusted content section.
- Adapted from obra/superpowers writing-skills (MIT) and pstack reflect and eval playbooks by Lauren Tan (MIT).

## 0.1.0 - 2026-07-08
